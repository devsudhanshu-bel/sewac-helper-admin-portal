# 1. `/api/dashboard/distributed-tags`

### Source Table

```text

TrackingLog

```

### Source Columns

```text

status

drySlno

wetSlno

```

### Business Rule

Count only RFIDs that were successfully distributed.

A tag is considered distributed when:

```text

status = FOUND

```

and RFID value is valid:

```text

NOT NULL

NOT "NULL"

NOT "N/A"

NOT ""

```

### Counting Logic

For each TrackingLog row:

```js

if (status === "FOUND") {



\\\\\\\&#x20;  if (isValidRFID(drySlno))

\\\\\\\&#x20;     distributedTags++;



\\\\\\\&#x20;  if (isValidRFID(wetSlno))

\\\\\\\&#x20;     distributedTags++;



}

```

### Example

| drySlno | wetSlno | status |
| ------- | ------- | ------ |
| 1208    | 1339    | FOUND  |

Counts as:

```text

2 distributed tags

```

---

| drySlno | wetSlno | status |
| ------- | ------- | ------ |
| 1208    | NULL    | FOUND  |

Counts as:

```text

1 distributed tag

```

---

| drySlno | wetSlno | status    |
| ------- | ------- | --------- |
| NULL    | NULL    | NOT_FOUND |

Counts as:

```text

0

```

# 2. `/api/logs/daily-counts`

### Source Table

```text

TrackingLog

```

### Source Columns

```text

createdAt

status

drySlno

wetSlno

```

### Business Rule

For each day:

```text

count number of RFID tags distributed

```

NOT

```text

count rows

```

and NOT

```text

count citizens

```

### Logic

For every TrackingLog row:

```js

if (status === "FOUND") {



\\\\\\\&#x20;  if (isValidRFID(drySlno))

\\\\\\\&#x20;     dailyCounts\\\\\\\\\\\\\\\[date]++;



\\\\\\\&#x20;  if (isValidRFID(wetSlno))

\\\\\\\&#x20;     dailyCounts\\\\\\\\\\\\\\\[date]++;



}

```

### Result

```json

\\\\\\\\\\\\\\\[

\\\\\\\&#x20; {

\\\\\\\&#x20;   "date": "2026-05-18",

\\\\\\\&#x20;   "count": 56

\\\\\\\&#x20; }

]

```

means

```text

56 RFID tags distributed

on 18-May

```

NOT

```text

56 scans

```

NOT

```text

56 citizens

```

---

# Relationship Between These Two Endpoints

They should ALWAYS satisfy:

```text

SUM(daily-counts)

=

distributed-tags

```

Example:

```text

18-May = 56

19-May = 107

20-May = 79

...

27-May = 59

\\\\\\\\----------------

Total = 1202

```

Then:

```json

{

\\\\\\\&#x20; "distributedTags": 1202

}

```

must match.

And currently yours does.

So these two endpoints are now internally consistent.
